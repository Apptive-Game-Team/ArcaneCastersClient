# 전투 캐릭터 모션과 프레임 배정

2026-11-09 제작 기준. 아래 배정표는 전용 동작까지 포함한 목표치다. 실제 프리팹의 연결 범위는 [적용 현황](#적용-현황)에 기록한다. 프레임 수는 **12fps로 재생할 때의 스프라이트 칸 수**다. 4칸은 약 0.33초, 6칸은 0.50초, 8칸은 약 0.67초다. 홀드와 기존 포즈를 포함하므로 신규 PNG 수는 더 적을 수 있다. 분사·돌진·설치처럼 지속 시간이 정해진 행동은 서버 상태에 맞춰 칸을 반복하거나 재생 시간을 조정한다.

## 프레임 제작과 연결

- 전투 이벤트가 도착한 순간에 발사·타격 포즈를 보여준다. 선행 예고가 있는 공격은 그 구간에 준비 자세를 재생한다. 예고가 없는 공격의 준비 자세는 대기 또는 조준에 활용한다.
- 걷기 프레임의 발은 현재 서버 이동 속도에 맞춰 재생한다. 피벗, PPU, 몸통 배율, 카메라 각도는 모션 전체에 같은 기준을 쓴다.
- 첫 수습 마법생의 시전 6칸은 뻗기 포즈, 뻗기 홀드, 반동, 회수, 복귀 직전, 최신 대기·조준 자세로 배정한다. 조준 진입 4칸은 내림, 들어 올리기 두 포즈, 세움으로 배정한다.
- 수습 마법생의 기본 외형은 `Resources/PlayerAppearances/default` 세 포즈가 인게임 기준이다. 후보 시트의 발·얼굴 크기를 원본과 비교하고 지팡이 결정 중심을 기록한다. 기존 커스텀 피벗과 오른쪽 방향을 유지한다.
- 투사체와 오라는 별도 레이어로 둔다. 시전이 끝났을 때 최신 카드 선택에 따라 조준 또는 대기로 복귀한다. 각 외형에 프레임을 별도로 연결하고, 완성 세트가 없는 외형은 자체 기존 포즈를 사용한다.

현재 포즈와 연결은 [애니메이션 에셋 기준](ANIMATION-ASSETS.md)을 참고한다.

## 수습 마법생 기본 외형

[12fps 반복 재생](concept/combat-animation-20261109/player-cast-preview.gif)에는 기존 세 포즈와 새 중간 포즈 네 장을 사용했다. 확대본과 전투 화면에서 작게 보일 때의 모습을 함께 배치했다. 기존 대기 포즈를 기준으로 기본 외형의 조준·시전 포즈 여섯 장의 로브, 망토, 피부, 머리색을 보정했다. 색을 보정하기 전후에 각 프레임의 알파가 일치하는지 확인했다.

| 구간 | 순서 |
|---|---|
| 조준 진입 4칸 | 대기 → `aim-lift-start` → `aim-lift-end` → 지팡이 세움 |
| 시전·대기 복귀 6칸 | 기존 시전 → 기존 시전 홀드 → `cast-recoil` → `cast-recover` → `aim-lift-start` → 대기 |

추가 프레임은 좌우에 32px 여백을 더한 1045×1245 캔버스를 사용한다. 원본과 같은 위치에 보이도록 원본 피벗에 해당하는 위치를 `(400, 1236)`으로 옮겼다. 네 PNG 모두 가장자리에 알파 32를 초과하는 픽셀이 없다.

`Player.prefab`에 기본 외형의 조준·복귀 프레임과 프레임별 지팡이 결정 위치를 연결했다. 기본 외형의 조준 자세는 서버의 카드 선택 효과를 받으면 재생한다. 시전 이벤트가 오면 곧바로 지팡이를 뻗고, 현재 카드 선택에 따라 대기 또는 조준으로 돌아온다. 오라는 각 프레임의 결정 위치를 따라가며 반대편 플레이어에서는 좌우로 뒤집힌다.

제작 도구는 내장 `imagegen`이다. [조준 진입 프롬프트](concept/combat-animation-20261109/player-aim-lift.prompt.txt), [시전 복귀 프롬프트](concept/combat-animation-20261109/player-cast-intermediates.prompt.txt), [색 비교용 프롬프트](concept/combat-animation-20261109/player-palette-match.prompt.txt)를 함께 보관한다.

## 첫 소환수 네 종의 이동과 공격

[프리팹 재생 순서 미리보기](concept/combat-animation-20261109/unit-motion-preview.gif)는 대기, 이동, 공격 순서다. 새 프레임은 각 유닛의 기존 크기와 PPU, 피벗으로 가져온다.

| 유닛 | 이동 | 공격 |
|---|---|---|
| 비전 보병 | **8칸**. 기존 두 발걸음에 발이 서로 지나가는 자세를 추가 | **6칸**. 타격 → 팔의 반동 → 가드 |
| 물 슬라임 | **6칸**. 압축 → 도약 → 착지 | **5칸**. 물 뱉기 → 입과 몸이 가라앉음 |
| 바위 골렘 | **8칸**. 디딤 → 무게 이동 → 디딤 | **8칸**. 전방 주먹 타격 → 회수 → 버팀 |
| 물의 궁수 | **6칸**. 활을 든 좌우 발걸음 | **6칸**. 발사 → 활의 반동 → 다시 당김 |

이동 프레임은 위치 업데이트가 이어지는 동안 반복된다. 공격은 기존 타격·발사 자세부터 재생하며 진행 중인 이동보다 우선한다. 새 대기·피격·퇴장 프레임의 수는 위 제작표에 남겨 둔다.

## 적용 현황

- `UnitSpriteMotionController`를 쓰는 44개 프리팹과 수습 마법생, 치킨 특공대, 분화구 운반수, 돌 가고일에 프레임을 연결했다. 총 48개다. 지상 유닛은 이동 6~8칸과 타격·회수 5~8칸을 사용한다. 정지 자세가 있는 유닛은 이동이 끝날 때 그 자세를 한 칸 거친다.
- 비행 유닛은 제자리에서도 날개와 꼬리의 반복이 이어진다. 가고일은 기존 3장 왕복과 재생 간격을 쓴다. 유닛별 그림은 [기본 방향 비교](concept/combat-animation-20261109/unit-direction-review.png)에 모았다.
- 분화구 운반수는 설치, 포격, 회수를 서버 상태로 구분한다. 치킨 특공대는 기존 낙하산 자세 뒤에 착지를 재생한다. 용암 갑각 악마는 소환 신호가 온 경우에 지면 돌파 프레임을 재생한다.
- 전기 계열 선택안을 적용했다. 번개 정령은 각진 먹구름과 밝은 핵으로, 창병은 번개 창을 든 부유 정령으로 바꿨다. 천둥 새 공격은 접은 날개로 급강하한 뒤 올라오는 8칸이다. [유닛별 이동·공격 연결](concept/lightning-lineup/motion/README.md)
- 꼬마 돌·바위 골렘·방벽 골렘·돌 마법사·포탑등이·돌 가고일의 암석을 검붉은 돌과 붉은 균열로 통일했다. 바위 슬라임에도 같은 암석 재질을 썼다. 포탑등이의 금속 포탑과 돌 마법사의 푸른 결정은 장비 식별에 쓰인다. [돌 골렘 계열 미리보기](concept/combat-animation-20261109/rock-clan-preview.gif)
- 불 슬라임은 좌상단 광원으로 오른쪽을 바라보는 기본 및 동작 자세를 다시 그렸다. 바람 정령의 역방향 이동 후보는 같은 방향의 자세로 교체했다.
- 고정 공격·지원 설치물의 발동과 복귀를 연결했다. 지상 대포와 지상 탑은 포탄이 생성될 때 포구에서 0.10초 동안 발사 효과를 재생한다. [설치물별 프레임](concept/fixed-attacker-motion/README.md)
- 1배속 미리보기 첫 화면에서 88종의 이동, 공격, 설치 전환 등을 스크롤로 볼 수 있다. 유닛 필터로 원하는 유닛의 동작만 모아 볼 수 있다.
- 마나 우물·집결·수리 토템은 10칸 반복, 풀 생성기·바람 토템·분화구는 실제 발동 시 5칸을 쓴다. 광란 토템과 룬은 서버가 계산한 범위에 파동 5칸을 남긴다. 감전 함정은 기존 방전 효과를 쓴다.
- 덩굴 두 종은 솟기 4칸과 퇴장 3칸, 과성장은 준비 6칸과 발동 3칸, 돌 잔해 두 크기는 생성 3칸과 붕괴 4칸을 쓴다. 지속 장판과 투사체·탄착 효과의 적용 범위와 유닛별 피격·퇴장은 이어서 확인한다.
- 전기 계열 8개 프리팹에 피격 3칸과 퇴장 5~6칸을 적용했다. 공중 유닛은 서버의 `Dying` 동안 추락 자세를 쓰고 착지 후 퇴장한다. [전기 계열 검수 기록](concept/combat-cue-review.md#전기-계열-피격과-퇴장)
- 돌 계열 7개 프리팹에 피격 3칸과 붕괴 5~6칸을 적용했다. 바위 골렘과 방벽 골렘은 크기가 다른 잔해를 사망 위치에 남긴다. [돌 계열 검수 기록](concept/combat-cue-review.md#돌-계열-피격과-퇴장)
- 보스 네 프리팹과 자연 계열 세 프리팹에 피격 3칸, 퇴장 5~8칸을 적용했다. [보스와 자연 계열 검수 기록](concept/combat-cue-review.md#보스와-자연-계열-피격과-퇴장)
- 불 계열과 폭탄 정령 9개 프리팹에 피격 3칸과 퇴장 5~6칸을 적용했다. 불 정령은 분사 효과가 생성되면 입을 열고, 공중 세 유닛은 추락 후 착지 자세로 이어진다. [불 계열과 폭탄 정령 검수 기록](concept/combat-cue-review.md#불-계열과-폭탄-정령-피격퇴장)
- 물·바람 계열 9개 프리팹에 피격 3칸을 적용했다. 거품 정령과 운룡은 1.25초 추락하고, 일반·타락 바람 정령은 치명타를 받은 높이에서 폭발한다. 바다뱀은 물줄기와 분사 자세를 함께 시작하고 머리와 몸통이 함께 사라진다. [물·바람 계열 검수 기록](concept/combat-cue-review.md#물바람-계열-피격과-퇴장)
- 남은 이동 유닛과 소환 시설 12개에 피격 3칸과 퇴장 5~6칸을 연결했다. 치킨 특공대는 낙하산·착지, 경계 운반자와 덩굴 군락은 소환을 피격보다 먼저 보여 준다. [이동 유닛과 소환 시설 검수 기록](concept/combat-cue-review.md#남은-이동-유닛과-소환-시설의-피격과-퇴장)
- 지상 대포와 탑 5종에 피격 3칸, 파괴 6칸을 연결했다. 불꽃 탑은 0.50초 비행 뒤 탄착점에서 폭발하며, 지상 대포와 지상 탑은 서버가 생성한 돌 잔해를 남긴다. [대포와 탑 검수 기록](concept/combat-cue-review.md#대포와-탑의-피격파괴-및-불꽃탄-탄착)
- 분화구 운반수는 운반과 설치 상태별 피격·파괴 그림을 쓴다. 체력이 있는 지원·발동 설치물 10종은 피격 3칸과 파괴 6칸을 쓰며 발동과 반복 동작은 서버 상태에 맞춰 이어진다. [지원·발동 설치물 검수 기록](concept/combat-cue-review.md#지원발동-설치물의-피격과-파괴)
- 번개 구름과 집결 토템은 수명 종료 시 12fps로 퇴장 5칸을 재생한다. 광란 토템 낙하와 룬 여섯 종의 폭발을 포함해 수명 종료·충돌 기록 14가지를 Unity에서 확인했다. [설치물 수명 종료와 룬 충돌](concept/combat-cue-review.md#설치물-수명-종료와-룬-충돌)
- 거품 정령은 지느러미와 머리 물결의 여섯 그림을 8칸(10fps, 0.80초)으로 반복한다. 눈과 몸통 높이를 맞췄으며 이동·공격을 공중 높이에서 보여 준다. [거품 정령 부유 재작업](concept/combat-cue-review.md#거품-정령의-부유-이동-재작업)
- 용암 정령은 주먹 생성과 함께 공격 상태를 보내 내려찍기 본체 자세를 재생한다. [88종 연결·검수 목록](concept/combat-motion-coverage.md)에 각 동작의 실제 연결 칸 수와 서버 기록을 정리했다.
- [전투 동작과 실제 발동 시점 검수](concept/combat-cue-review.md)에 확인한 서버 신호와 남은 동작을 정리했다.
