# 분화구 운반수
- 서버 키: `crater_carrier`
- 시전: 소환 (`CraterCarrierMagic` → `CraterCarrier`)
- 진영: 불타는 군단
- 원소: 불 + 돌 (카드의 대표 원소는 불)
- 역할: 지상 원거리 범위 포격, 중형 소환수

몸보다 큰 분화구 모양의 돌 박격포를 짊어지고 다니는 악마다.
검붉은 몸, 각진 현무암 갑각, 틈 안쪽의 용암빛을 사용한다.

이동 → 설치 → 포격 → 회수 → 이동 순서로 동작한다. 설치를 마치기 전에는 발사하지 않는다.
사거리 안에 적이 남아 있으면 설치 상태에서 공격 간격에 맞춰 계속 발사한다.
대상 사망·범위 이탈·이동 지시가 발생하면 회수한 뒤 이동한다.
기절은 준비·발사를 중단하고, 기절 종료 후에도 회수 단계를 건너뛰지 않는다.

`CraterShell`은 발사 시 복사한 지상 위치로 포물선을 그리며 날아간다.
피해는 착탄 때 한 번만 적용되고, 아군과 공중 대상은 제외한다.
운반수가 죽어도 이미 발사한 포탄은 남는다. 폭발 몸체 `CraterExplosion`은 표시 전용이다.
운반수가 전투로 사망하면 작은 돌 잔해를 남긴다.

서버의 `Deploying`·`Deployed`·`Recovering` 상태를 클라이언트가 그대로 재생한다.
설치와 회수는 같은 들고 있는 중간 자세, 포격은 땅에 고정한 자세를 사용한다.
동기화 복구와 도감 미리보기에도 같은 프리팹·상태 처리를 쓴다.

아트: `CraterCarrier.png`, `CraterCarrierDeployed.png`, `CraterCarrierRecovering.png`.
세 프레임은 192×162, PPU 110, Bottom Center와 동일한 원본 배율·발 기준선을 공유한다.
포탄과 착탄 효과는 기존 `FireworkShell` 이미지·`MagmaExplosion` 애니메이션을 재사용한다.
착탄 표시 크기는 서버의 실제 폭발 반경 gizmo에 맞춘다. 전투 수치는 database V045가 정본이다.
