# 비전 보병
- 서버 키: `arcane_infantry`
- 시전: 소환 (`ArcaneInfantryMagic` → `ArcaneInfantry`)
- 진영: 인간 마법 문명
- 원소: 무속성
- 역할: 지상 단일 대상 근접 공격

짧은 마도봉 끝에 푸른 마력을 몽둥이 모양으로 응축해 싸우는 기본 보병.
작은 투구, 스틸블루 흉갑, 청동 장식으로 기존 인간 문명의 병기·비전 강하대와 연결한다.

기존 지상 이동·대상 탐색·근접 타격을 사용한다. 공격 시에만 타격 프레임을 잠시 표시한다.
초기 수치와 소환 비용은 database V045에서 관리한다. 로컬 마법 ID나 조합식은 없다.

아트: `ArcaneInfantry.png`, `ArcaneInfantryAttacking.png`. 두 프레임은
128×81, PPU 70, Bottom Center로 동일하다. 원본 시트에서 같은 배율과 발 기준선을 사용했다.
생성 프롬프트는 `.art/concept/infantry-mortar-production-prompts/`에 보존한다.
