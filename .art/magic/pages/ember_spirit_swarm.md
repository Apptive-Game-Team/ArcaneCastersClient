# 불씨 정령 무리

- 서버 키: `ember_spirit_swarm`
- 현재 이름: 불씨 정령 무리
- 컨셉 이름: 잿불 악마 무리
- 시전 계열: 소환
- 진영: 지옥불 군단
- 상태: game 서버 구현 확인

## 컨셉

지옥불 군단의 독립 개체로 전장에 합류하는 잿불 악마 무리.

## 컨셉 설명

검붉은 갑각을 두른 정령 다섯 마리가 가깝고 먼 앞발·뒷발을 번갈아 디디며 지상 표적을 쫓는다. 각 정령은 표적에 닿는 순간 몸을 낮추고 앞발을 내민다.

## 설명

플레이어가 사용하는 **소환 계열 마법**이다.
게임플레이 사실은 아래 서버 코드에서 가져왔고, 세계관·아트 문장은
`.art/WORLD.md`와 `.art/STYLE.md`를 적용한 해석이다.

## 동작

1. 목표 지점 주변에 불씨 정령 다섯 마리를 소환한다.
2. 정령이 각자 지상 표적을 쫓아 근접 피해를 준다.
3. 클라이언트는 이동 거리에 맞춰 여덟 보행 자세를 고른다. 피해마다 공격 개체가 앞발을 내밀고 네 자세에 걸쳐 회수한다.

## 전투 프로필

| 항목 | 분류 | 코드 근거 |
|---|---|---|
| 기동 방식 | 지상 보행 | `FireSlimePrefabInitializer`의 `Slime`과 전투 녹화 |
| 전투 역할 | 전투 개체 | 부착 AI·마법 컴포넌트 기준 |
| 공격 형태 | 지상 근접 타격 | `Slime`의 `HitEvent` |
| 표적 | 지상 | `TargetMask::Ground` |
| 특수 이동·행동 | 추가 특수 이동 없음 | 부착 컴포넌트 기준 |
| 생명주기 | 소스에서 시간 제한을 직접 확인하지 못함 | 파괴·시간제한 컴포넌트 기준 |

## 서버 구조

| 항목 | 값 |
|---|---|
| 구현 클래스 | `EmberSpiritSwarmMagic` |
| 상위 클래스 | `AbstractSpawnMagic` |
| 주 프리팹 | `EmberSpirit` |
| 부가 프리팹 | 없음 또는 소스에서 직접 확인되지 않음 |
| 부착 컴포넌트 | 없음 또는 소스에서 직접 확인되지 않음 |
| 파라미터 키 | 없음 또는 소스에서 직접 확인되지 않음 |
| 오브젝트 파라미터 | `EMBER_SPIRIT` |

수치 자체는 런타임 DB 데이터다. 이 문서는 키만 기록하며 값을 추정하지 않는다.

## 아트 방향

검붉은 종이 갑각과 내부 용암광. 불꽃 정령이 아니라 악마 군단의 마법으로 표현한다.

- 공통 스타일: A — 2.5D 컷페이퍼
- 생성 참조: `.art/anchors/master-v2/MasterStyleKey.png`와 가장 가까운 재질 앵커
- 실루엣은 실제 동작이 읽혀야 한다. 공격 방향, 이동 방식, 설치 여부를 장식보다 우선한다.

## 미결 사항

- 서버 계약은 유지하더라도 표시명과 외형에서 `정령` 표현 제거 필요
- 상속 또는 다단 생성 경로를 수동 검토해야 함
