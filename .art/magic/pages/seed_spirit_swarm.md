# 씨앗 정령 무리

- 서버 키: `seed_spirit_swarm`
- 현재 이름: 씨앗 정령 무리
- 컨셉 이름: 씨앗 정령 군락
- 시전 계열: 소환
- 진영: 세계수 풀 정령
- 상태: game 서버 구현 확인

## 컨셉

세계수 풀 정령의 독립 개체로 전장에 합류하는 씨앗 정령 군락.

## 컨셉 설명

세계수의 씨앗 정령 네 개체가 밑동의 잎을 번갈아 펴고 접으며 지상 표적을 좇는다. 피해가 들어오면 해당 정령의 앞 잎이 짧게 뻗고, 새싹과 흰 꽃이 몸통의 움직임 뒤에 기울어진다.

## 설명

플레이어가 사용하는 **소환 계열 마법**이다.
게임플레이 사실은 아래 서버 코드에서 가져왔고, 세계관·아트 문장은
`.art/WORLD.md`와 `.art/STYLE.md`를 적용한 해석이다.

## 동작

1. 목표 지점 주변에 씨앗 정령을 소환한다.
2. 정령들이 각각 지상 표적을 추적하고 근접 타격한다.
3. 씨앗 둥지에서도 같은 정령이 생성된다. 과성장이 범위 안 아군 정령을 고목 수호자로 바꾸면 새 개체는 기존 위치에서 등장한다.

## 전투 프로필

| 항목 | 분류 | 코드 근거 |
|---|---|---|
| 기동 방식 | 지상 보행 | `SeedSpiritPrefabInitializer`와 `Slime` |
| 전투 역할 | 전투 개체 | 부착 AI·마법 컴포넌트 기준 |
| 공격 형태 | 지상 근접 타격 | `HitEvent`에서 앞 잎이 뻗는다 |
| 표적 | 지상 | `TargetMask::Ground` |
| 특수 이동·행동 | 추가 특수 이동 없음 | 부착 컴포넌트 기준 |
| 생명주기 | 소스에서 시간 제한을 직접 확인하지 못함 | 파괴·시간제한 컴포넌트 기준 |

## 서버 구조

| 항목 | 값 |
|---|---|
| 구현 클래스 | `SeedSpiritSwarmMagic` |
| 상위 클래스 | `AbstractSpawnMagic` |
| 주 프리팹 | `SeedSpirit` |
| 부가 프리팹 | 없음 또는 소스에서 직접 확인되지 않음 |
| 부착 컴포넌트 | 없음 또는 소스에서 직접 확인되지 않음 |
| 파라미터 키 | 없음 또는 소스에서 직접 확인되지 않음 |
| 오브젝트 파라미터 | `SEED_SPIRIT` |

수치 자체는 런타임 DB 데이터다. 이 문서는 키만 기록하며 값을 추정하지 않는다.

## 아트 방향

잎·씨앗·덩굴의 겹친 컷페이퍼 형태로 생장 방향을 보여준다.

- 공통 스타일: A — 2.5D 컷페이퍼
- 생성 참조: `.art/anchors/master-v2/MasterStyleKey.png`와 가장 가까운 재질 앵커
- 실루엣은 실제 동작이 읽혀야 한다. 공격 방향, 이동 방식, 설치 여부를 장식보다 우선한다.
