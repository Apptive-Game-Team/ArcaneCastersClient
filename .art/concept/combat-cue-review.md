# 전투 동작과 실제 발동 시점 검수

이동은 서버의 위치 변화에 맞춰 반복하고, 공격 자세는 실제로 관측할 수 있는 발사·피격·상태 신호에 연결한다. 공격 준비 시간이 따로 전송되지 않는 경우에는 타격이나 발사 자세부터 재생한다. 전체 유닛 1배속 미리보기

| 유닛과 역할 | 재생 조건과 프레임 |
|---|---|
| 지상 대포·지상 탑 | 포탄이 생성되면 발사 방향의 포구에 점화 → 불꽃 → 연기 3칸(30fps, 0.10초). 화면에서 보이는 포탄도 그 자리에서 출발한다. 포신 반동은 기존 4칸(12fps). |
| 바위 포탑·전기 탑·용 탑 | 바위 포탑은 같은 `RockShot`을 투석 팔로 던진다. 전기 탑은 `ElectricShot`을 발사하고 용 탑은 이동하는 불길을 소환한다. 각 발동 자세 4칸(12fps)을 사용한다. |
| 불꽃 탑 | `FireworkShell` 비행이 시작되는 틱에 본체 발동 4칸(12fps)을 재생한다. Java·Rust 서버에서 같은 `Attack` 상태를 보낸다. 폭발은 기존대로 탄착 뒤에 일어난다. |
| 폭풍 사슴 | 돌진과 공포 후퇴는 달리기 8칸(12fps). 실제 충돌 피해의 `HitEvent`에 낮춘 자세 2칸과 회복 1칸(0.25초)을 재생한다. 피해가 없는 이동에는 달리기만 나온다. 고속 충돌의 번개 효과는 기존 조건을 따른다. |
| 바람 정령·타락한 바람 정령 | 서버가 폭발을 계산한 위치에 바람 조각이 퍼지고 흐려지는 6칸(12fps)을 재생한다. 같은 폭발 신호를 받은 개체는 삭제 시점에 효과를 한 번 더 내지 않는다. |
| 일반·모험 경계 운반자 | 실제 소환수가 생기는 틱에 차원문 방출 2칸, 약해짐 2칸, 대기 2칸(12fps)을 재생한다. 이동은 후퇴 8칸을 공유한다. |
| 불의 군주·씨앗 둥지·모험 슬라임 둥지 | 하급 악마나 슬라임, 씨앗 정령이 생성되면 본체 방출 2칸, 회수 2칸, 대기 2칸(12fps)을 재생한다. 여러 마리가 동시에 생성되면 각 위치에 효과가 하나씩 나온다. |
| 일반·모험 덩굴 군락 | 일반 군락은 적이 있는 위치에 덩굴을 생성할 때 줄기를 세운다. 모험 군락은 주변에 소환수가 생성될 때 같은 본체 자세를 쓴다. 생성 효과는 각 소환 위치에서 6칸(12fps)을 재생한다. |
| 불·돌·전기·바람 소환소 | 기존 씨앗 둥지 프리팹의 본체와 6칸 소환 동작을 공유한다. 각 소환소는 해당 속성의 슬라임을 생성한다. |
| 포탑등이 | 지상 공격은 팔 타격 6칸(12fps). 공중 목표에 `RockShot`을 발사하면 대공 반동 4칸(12fps)과 포구 효과 3칸(30fps)을 재생한다. |
| 불 정령·바다뱀 | 불 정령은 불꽃을 생성할 때 `SprayRelease`를 받아 분사 6칸, 회수 2칸, 대기 2칸을 재생한다. 분사 자세와 불꽃 효과는 함께 시작해 0.50초간 지속한다. 바다뱀도 물줄기를 생성할 때 같은 신호를 받는다. 분사 4칸을 0.35초에 맞추고 회수 2칸과 대기 1칸을 쓴다. 둘 다 12fps다. |
| 천둥 새·폭탄 정령 | 천둥 새는 Java·Rust 서버가 급강하 시작을 알릴 때 날개를 접고 올라오는 8칸(12fps)을 재생한다. 폭탄 정령의 본체는 투하에 맞추고, 별도 폭탄이 떨어진 곳에서 폭발한다. |
| 거품 정령 | 높이 3에서 부유하며 공중 적에게 거품을 발사한다. 이동은 지느러미와 머리 물결의 그림 6장을 8칸(10fps, 0.80초)으로 반복한다. 눈의 위치와 몸통 높이를 맞춰 지느러미를 젓는 동안 몸이 뛰는 느낌을 줄였다. |
| 분화구 운반수·치킨 특공대 | 운반수는 서버 상태에 따라 운반·설치·포격·회수 자세를 쓴다. 치킨 특공대는 공중에서 낙하산 자세를 유지하고 착지 후 지상 자세로 바뀐다. |
| 거품 생성기·생명의 나무·치유 토템·거신의 잔해 | 각각 보호·생명력·치유·주먹 소환 시 본체 발동과 복귀 4칸(12fps). 소환물과 범위 효과의 시간은 기존 서버 신호를 따른다. |
| 모험 벽돌 골렘 | 내려찍기 경고가 나오는 1초 동안 팔을 들어 올린 자세를 유지한다. 타격 신호에 뻗기와 회복 5칸(12fps)을 재생한다. 근거리 휩쓸기는 접촉 틱부터 별도 4칸을 0.40초 동안 재생한다. 불씨 정령 소환은 6칸(12fps)이며, 공격 예고나 타격과 겹치면 공격 자세와 각 소환 지점의 효과가 함께 나온다. |
| 사악한 나무 거인·모험 나무 거인 | 주먹 뻗기 6칸, 붙잡아 끌어오기 8칸, 불주먹 7칸. 팔 투사체의 수명과 접촉 시점에 맞춰 본체를 재생한다. 팔이 닿은 뒤 회수 자세는 0.125~0.25초 추가한다. |
| 덩굴 마녀 | 성공한 일반 시전에 6칸, 분노 발동에 8칸, 연속 덩굴의 각 시전에 5칸을 재생한다. 체력이 절반 이하가 되면 잎 오라가 뜨며 첫 발사가 같은 틱이면 본체는 발사 자세를 우선한다. |
| 마나 우물·집결 토템·수리 토템 | 설치된 동안 10칸(12fps)을 반복한다. 우물은 수면의 빛, 집결은 꼭대기 불꽃, 수리는 결정만 주로 움직인다. 수리 토템은 주변 설치물의 지속 시간을 보존한다. |
| 풀 생성기·분화구 | 잎밭이나 불씨가 실제로 생기는 틱에 발동 2칸, 회복 2칸, 대기 1칸(12fps). 풀 생성기는 불이 번진 칸을 건너뛰며, Rust에서 씨앗 정령 아래 덩굴이 생성될 때도 같은 동작을 쓴다. |
| 바람 토템 | 0.5초 간격의 밀어내기 영역 갱신에 천이 펴지는 2칸, 회복 2칸, 대기 1칸(12fps)을 재생한다. 서버가 보낸 영역을 향해 좌우를 바꾼다. |
| 광란 토템·감전 함정 | 광란 토템은 낙하하다 착지하거나 적과 충돌하면 사라지고 적용 범위에 붉은 파동 5칸(12fps)이 남는다. 감전 함정은 감지 후 기존 방전 효과가 0.26초 동안 남는다. |
| 불·물·자연·바위·번개·바람 룬 | 적과 충돌해 피해를 계산하고 룬을 없애는 틱에 속성별 파동 5칸(12fps)을 재생한다. 파동은 피해 범위의 지름과 서버 발동 위치를 사용한다. |
| 덩굴·거대 덩굴 | 생성 틱부터 솟기 4칸(12fps). 속박이 유지되는 동안 기본 자세를 유지하고, 서버가 제거하면 줄기가 접히는 3칸을 그 자리에 남긴다. |
| 과성장 | 생성 시 잎이 모이는 6칸(12fps)을 재생한다. 서버가 씨앗 정령을 소환하거나 나무 골렘으로 진화시키는 틱에 잎이 퍼지고 흩어지는 3칸을 재생한다. |
| 작은·중간 돌 잔해 | 생성 시 내려앉기 3칸, 수명이 끝나면 무너짐 4칸(12fps). 돌 폭파와 대지 소환에 소비된 잔해는 무너짐을 생략하고 서버가 생성한 폭발·잔해·소환수가 보인다. |

미리보기는 연결된 클립을 기준으로 집계하며 일반 근접·원거리 유닛의 기존 이동과 타격도 포함한다. 모험 경계 운반자는 일반 경계 운반자와 같은 외형을 쓰므로 기존 후퇴 8칸을 연결했다. [프레임 배정표](../COMBAT-ANIMATION-PLAN.md)

## 전체 검수 완료 기준

- [x] 바람 정령과 타락한 바람 정령은 실제 폭발 위치와 시점에 맞춰 폭발과 소멸을 보여 준다. Java·Rust의 폭발 신호와 Unity의 위치 및 중복 방지를 확인했다.
- [x] 일반·모험 경계 운반자는 올챙이가 생성된 프레임에 차원문 방출 자세를 보여 준다. Java·Rust의 생성 타이밍과 Unity의 이벤트 재생을 확인했다.
- [x] 불의 군주, 씨앗 둥지, 슬라임 둥지 두 종, 일반·모험 덩굴 군락과 기존 속성 소환소는 실제 소환 프레임에 본체 발동과 생성 위치별 효과를 재생한다. Unity에서 경계 운반자를 포함한 12종의 프리팹과 생성 위치를 확인했다.
- [x] 나무 거인과 덩굴 마녀의 주요 패턴을 다른 자세와 효과로 구분했다. 나무 거인의 세 공격은 기록 전투에서 접촉과 본체 자세를 대조했다.
- [x] 88종의 이동·타격·발동을 프리팹과 서버 동작에 대조했다. 85종의 기본 서버 기록과 장주기·특수 동작의 추가 기록을 남겼다. 수습 마법생은 입력 상태를 검수했다. 현재 Rust 타입이 없는 전기 창병과 돌 가고일은 Unity에서 별도로 재생했다. [연결·검수 목록](combat-motion-coverage.md)
- [x] Unity 전투 리소스 132개와 관련 서버 테스트를 확인했다. 로컬 PVP·PVE 매치와 서버 시뮬레이션 기록을 재생해 발사, 충돌, 자폭, 소환, 보스 패턴을 검수했다.
- [x] 비공개 미리보기 28판의 88종 295개 클립을 Chromium에서 불러와 첫 프레임을 검사하고, 좌우 전환 버튼 9개를 확인했다. 덩굴 마녀 연속 시전은 서버 기록의 시작 간격으로 재생한다.

Rust의 프리팹 타입 136개를 미리보기 목록과 대조했다. 미리보기 88종 중 86종은 Rust 프리팹 타입과 일치한다. 전기 창병과 돌 가고일은 Unity 미리보기에 있으며 현재 Rust 타입 목록에는 없다. 미리보기에 따로 등록하지 않은 50개는 투사체·낙하체·탄착 효과·지속 장판·지형이다. 발사·생성·충돌을 읽는 데 필요한 효과는 해당 동작에 포함한다. 벽은 경기장 경계 충돌체이며 독립 프리팹 스프라이트가 없다.

## 전투에서 볼 항목

1. 대포와 지상 탑을 각각 양쪽에 배치한다. 포신 앞의 섬광과 포탄 출발 위치가 일치하는지, 포구에서 나온 연기와 대상에 맞는 효과를 구분할 수 있는지 본다. 바위 포탑에는 투석 자세가 나온다.
2. 불꽃 탑에서 발동과 탄착이 두 시점으로 읽히는지 본다. 폭풍 사슴은 빗나간 돌진과 실제 충돌을 비교하고, 충돌 뒤 공포 후퇴로 자연스럽게 넘어가는지 본다.
3. 불 정령과 바다뱀의 분사 자세가 효과와 함께 끝나는지 본다. 색과 피벗이 바뀌어 화면에서 몸이 깜빡이거나 튀어 보이는 프레임이 있으면 유닛과 동작을 기록한다.
4. 일반 덩굴 군락을 적과 떨어뜨려 배치해 적 발밑의 효과와 군락 본체의 자세를 본다. 모험 둥지에서 여러 마리가 나오면 생성 위치마다 효과가 따로 보이는지 확인한다.

나무 거인은 팔 투사체가 출발할 때 보스와 공격 종류를 함께 식별한다. 펀치는 투사체 수명의 55%에, 붙잡기는 22%에 접촉하며 이어서 0.8초간 끌어온다. 불주먹은 45%에 닿는다. 덩굴 마녀는 체력이 절반 이하가 되면 사거리 안의 적에게 0.45초 간격으로 네 번 시전한다. 사거리에 적이 없으면 시전이 늦어진다.

Unity 에디터 검사에서 포구의 좌우 위치, 스프라이트 피벗, 섬광 종료, 투석기 제외, 폭풍 사슴 충돌과 복귀, 불 정령 유지 구간을 확인했다. Java 불꽃 탑 관련 테스트 9개와 Rust 시뮬레이션 테스트 767개가 통과했다. 실제 전투 장면의 타이밍과 가독성은 위 항목으로 검수한다.

소환 변경 후 Java의 둥지·차원문·자폭 테스트와 Rust `ac-sim`의 단위·통합 테스트가 통과했다. Rust 서버의 `ac-parity record`로 대표 마법 9개의 프레임을 기록했다. 경계 운반자 18회, 씨앗 둥지 10회, 덩굴 군락 13회에서 소환수가 생긴 프레임과 생성 위치가 효과 신호와 일치했다.

서버가 기록한 11개 상황을 Unity Play Mode에서 1배속으로 재생하고 화면을 캡처했다. 대포 발사, 차원문·둥지·군락 소환, 바람 정령 자폭, 폭풍 사슴 충돌, 천둥 새 급강하, 바다뱀 분사, 나무 거인의 주먹·붙잡기·불주먹이 포함된다. `.generated/combat-cue-playmode/`의 PNG와 `.generated/combat-replay-unity.log`에 결과를 남겼다. 이 검수는 서버가 실제 계산한 프레임을 사용한 오프라인 재생이다.

## 대포와 탑의 피격·파괴 및 불꽃탄 탄착

지상 대포, 지상 탑, 전기 탑, 바위 포탑, 용 탑, 불꽃 탑에 피격 3칸과 파괴 6칸을 연결했다. 기존 12fps 발사 4칸을 유지하고, 발사 도중 체력이 줄면 발사 자세를 끝까지 보여 준다. 그 사이 받은 피해는 피격 자세를 늦게 재생하지 않는다. 지상 대포와 지상 탑의 포구 섬광은 0.10초간 재생된다. 두 무기는 서버가 제거 틱에 만든 작은 돌 잔해를 남긴다.

Rust 서버에 시험 피해를 넣고 대상을 배치한 여섯 기록을 Unity Play Mode에서 1배속으로 재생했다. 피격, 회복, 발사 도중 피해, 파괴가 전용 그림으로 표시됐다. 대포 두 종은 왼쪽 포구 섬광의 위치에서 실제 `RockShot` 스프라이트가 출발했고, 바위 포탑에는 섬광이 나오지 않았다. 불꽃탄은 0.50초 뒤 서버가 만든 탄착 위치에서 폭발 스프라이트가 커졌다. 녹화 프레임과 Unity 캡처는 `.generated/combat-install-reactions/`에 보관한다.

비공개 미리보기 버전 21에 88종 266개 클립을 반영했다. Chromium에서 두 포구의 좌우 위치, 대포 잔해, 불꽃탄의 0.50초 비행과 0.80초 폭발 표시, 새 피격·파괴 클립 6쌍을 확인했다. 남은 체력 보유 대상은 분화구 운반수와 지원·발동 설치물 10개다.

## 분화구 운반수의 상태별 피격·파괴

박격포를 메고 있을 때와 땅에 놓았을 때 각각 피격 3칸, 파괴 6칸을 쓴다. 설치·회수 전환과 발사 반동이 피격보다 우선한다. 파괴되면 현재 상태에 맞는 본체 그림을 재생하고 서버가 같은 위치에 생성한 작은 돌 잔해가 남는다. Rust 서버 기록 세 개를 Unity에서 재생해 운반 중 파괴, 설치 후 포격 중 파괴, 회수로 피격 자세가 끊긴 뒤 다시 운반 상태에서 파괴되는 경우를 확인했다. 그림과 화면은 `.generated/combat-install-reactions/`에 보관한다.

## 로컬 PVP의 전투 패킷 검수

격리한 PostgreSQL에 데이터베이스 `origin/dev`의 마이그레이션 56개를 적용하고 로컬 Rust 서버에 STOMP 검수 클라이언트를 연결했다. 시작 덱의 카드로 진행한 PVP는 무승부, PVE는 생존 승리였다. 양쪽 PVP 클라이언트의 시전은 각각 7회 승인됐다. PVE는 3회 승인됐고 종료 직후 한 차례 시전을 거부했다.

PVP의 첫 동기화 스냅샷과 이후 전투 프레임 279개를 Unity에서 1배속으로 재생했다. 바위 포탑의 돌 투척 13회와 전기 탑의 전기탄 발사 7회에서 본체 자세가 투사체 출발과 일치했고, 바람 정령은 제거 틱에 서버가 보낸 높이에서 한 번 폭발했다. 독립 스프라이트가 없는 경기장 경계는 화면 재생에서 제외했다. 로컬 매치 로그와 Unity 화면은 `.generated/combat-live-smoke/v21/`에 보관한다.

추가 로컬 매치에는 검수용 덱을 사용했고, 모험 13의 승리 조건은 30초 생존으로 설정했다. PVP에서 지상 대포 발사 4회, 지상 탑 발사 1회, 불꽃탄 발사 26회와 경계 운반자 소환 2회를 기록했다. 모험에서는 벽돌 골렘의 내려찍기 예고 5회, 타격 4회와 불씨 정령 5마리씩 두 차례 소환을 기록했다. 마지막 예고는 매치 종료 전에 타격으로 이어지지 않았다. 두 매치의 스냅샷과 전투 프레임은 `.generated/combat-live-smoke/targeted/`에 보관한다.

두 매치의 전투 프레임을 Unity에서 1배속으로 재생했다. PVP에서는 대포·탑의 포구 위치, 불꽃탄의 서버 탄착 위치 25회, 경계 운반자의 소환 위치 두 곳이 일치했다. 마지막 불꽃탄은 매치 종료 전에 탄착하지 않았다. 모험에서는 내려찍기 예고와 타격이 구분됐고, 피격과 타격이 겹쳐도 타격 자세가 먼저 나왔다. 불씨 정령이 나온 다섯 위치에서 효과가 재생됐다. 두 차례 소환 중 한 번은 본체의 소환 자세가 나왔고, 내려찍기 예고와 겹친 한 번은 예고 자세를 유지했다.

근거리 휩쓸기는 별도의 Rust 서버 기록에서 피해와 기존 효과가 발생하는 틱에 같은 보스와 방향의 자세 신호를 확인했다. Unity에서 그 효과와 0.40초 본체 자세를 함께 재생했다. Rust 벽돌 골렘 테스트 8개가 통과했다. 비공개 미리보기 23판에 88종 292개 클립을 반영했으며, Chromium에서 휩쓸기 시간과 방향, 다섯 소환 위치를 확인했다.

## 지원·발동 설치물의 피격과 파괴

거품 생성기, 생명의 나무, 치유 토템, 거신의 잔해, 마나 우물, 수리 토템, 풀 생성기, 바람 토템, 분화구와 감전 함정에 12fps 피격 3칸과 파괴 6칸을 연결했다. 거품·치유·거신 주먹 발동 중에는 발동 자세가 우선한다. 풀 생성기와 분화구는 서버가 잎밭과 불씨를 만든 틱에 발동하며, 바람 토템은 0.50초마다 발동 자세를 재생한다. 마나 우물과 수리 토템의 10칸 반복은 피격 뒤 이어진다.

Rust 서버 기록을 Unity에서 재생해 피해로 파괴되는 열 가지 경우와 감전 함정이 스스로 발동해 소모되는 경우를 확인했다. 거신의 잔해는 파괴된 위치에 중간 돌 잔해를 남겼다. 감전 함정은 소모 틱에 방전이 한 번 나왔고, 피해로 파괴된 기록에는 방전이 없었다. 대포·탑·분화구 운반수 관련 Rust 테스트 19개와 Java 테스트 16개가 통과했다. 지원·발동 설치물의 기록과 캡처는 `.generated/combat-install-reactions/`에 보관한다.

비공개 미리보기 버전 22에 88종 290개 클립을 반영했다. Chromium에서 설치물 10종의 피격·파괴, 분화구 운반수의 상태별 자세, 마나 우물과 수리 토템의 반복, 운반수와 거신의 잔해를 확인했다.

체력을 가진 별도 운반수와 설치물 17개 모두에 피격과 파괴를 연결했다. 수명·발동으로 사라지는 대상과 투사체·탄착의 전체 대조는 이어서 진행한다.

## 설치물 수명 종료와 룬 충돌

번개 구름은 서버가 제거할 때 공중에서 흩어지고, 집결 토템은 불꽃이 잦아든 뒤 사라진다. 두 퇴장에 12fps로 5칸을 쓴다. Unity에서 Rust 서버 기록 14가지를 재생해 제거 위치, 중복 효과와 정리를 확인했다. 2.50초가 넘는 사례는 제거 0.75초 전까지 건너뛴 뒤 1배속으로 재생했다.

룬 여섯 종은 시험 대상에게 피해가 들어간 0.65초 틱에 각 색상의 파동을 한 번 내보냈다. 시험 파동은 서버 지름 6과 지속 시간 0.42초를 따랐다. 광란 토템은 1.50초 낙하 뒤 지면에서 한 번 폭발했다. 덩굴 두 종, 돌 잔해 두 크기, 과성장도 퇴장과 정리를 확인했다. 시험 기록과 캡처는 `.generated/combat-install-reactions/`에 보관한다.

## 거품 정령의 부유 이동 재작업

이동이 뛰는 동작처럼 보인다는 검수에 따라 이동 그림을 다시 제작했다. 몸통을 길게 늘이거나 낮추는 두 자세 반복을 지느러미 여섯 자세로 교체했다. 아래의 작은 거품은 함께 뒤따르고 지느러미와 머리 물결이 이어서 움직인다. 원래 눈의 위치를 기준으로 여섯 장을 같은 배율로 맞췄다.

기본 외형과 master-v2를 참조해 내장 이미지 생성 도구로 제작했다. [제작 프롬프트](combat-cue-art/bubble-hover-prompt.txt)와 [생성 원본](combat-animation-20261109/bubble-hover-source.png)을 보관했다. Unity에서 정상 생성과 이동 경로로 1.60초를 촬영해 여섯 그림, 0.80초 반복과 서버 높이 3을 확인했다. 이 이동 검수의 위치 입력은 직접 구성했다. [Unity 1배속 촬영](combat-animation-20261109/bubble-hover-live.gif)

Chromium에서 부유 이동 8칸과 공격 중 높이 유지, 서버 기록을 따른 추락을 확인했다. 분화구 운반수의 포탄은 기록된 0.20초 곡선 궤적과 탄착으로, 폭탄 정령의 폭탄은 1.60초 낙하와 탄착으로 미리보기에 연결했다. 두 궤적은 좌우 방향과 효과 종료를 확인했다.

비공개 미리보기 24판에 설치물 수명 종료와 룬 충돌을 반영했다. 25판에는 거품 정령의 부유 이동과 두 포탄의 비행·탄착을 반영했다. 두 판 모두 88종 295개 클립이다. Rust `ac-sim` 회귀 검증에서 단위 테스트 768개와 통합 테스트가 통과했다.

## 용암 정령의 타격 신호와 전체 리소스 대조

시험 지상·공중 대상을 배치해 Rust production simulation으로 85개 유닛·설치물을 각각 6.50초 기록했다. 용암 정령은 MagmaFist를 만들 때 Attack 상태가 빠져 본체 공격 그림을 재생하지 않았다. Java와 Rust의 SummonerMob에 주먹 생성 직후 Attack 상태를 연결했다. 이 컴포넌트의 실제 호출자는 두 서버 모두 용암 정령이다.

Unity에서 새 서버 기록을 1배속 재생해 여섯 타격 모두 주먹 생성과 본체 자세가 같은 틱에 나오는지 확인했다. Rust SummonerMob 테스트 5개와 Java SummonerMobTest의 두 테스트가 통과했다. Unity 리소스 검사에서는 서버 타입과 미리보기의 전투 프리팹 132개에 대해 스크립트, 프레임 배열과 직렬화 참조를 확인했다. 결과와 타격 캡처는 `.generated/combat-full-audit/`에 보관한다.

미리보기의 공중 유닛은 서버 기록 높이를 이동·공격·피격에 함께 적용했다. Chromium에서 공중 타입 열 종의 피격·퇴장 높이와 용암 정령의 0.80초 지면 주먹 효과를 확인했다.

비공개 미리보기 26판에 공중 높이와 용암 정령의 지면 주먹 효과를 반영했다. 88종 295개 클립이다. 수정 뒤 Rust `ac-sim` 단위 테스트 768개와 실행된 통합 테스트가 통과했다. 이 환경에서 Graphify 실행 파일을 찾지 못해 그래프 갱신은 수행하지 못했다.

## 모험 소환 위치와 거품 생성기

비공개 미리보기 27판에 네 종류의 서버 소환 위치를 반영했다.

Rust 시뮬레이션을 12.50초 기록했다. 두 슬라임 둥지는 9.95초에 중앙 한 곳, 덩굴 군락은 9.95초에 좌우 두 곳, 덩굴 마녀는 7.95초에 좌우 두 곳에서 소환했다. 각 신호의 위치는 같은 틱의 아군 생성 위치와 일치했다. Chromium에서 네 클립의 효과 개수와 위치를 확인했다. 거품 생성기는 아군을 배치했을 때 0.75초에 발사 신호, 본체 공격 상태와 아군 보호막 적용을 보냈다.

덩굴 마녀의 20.50초 추가 기록은 시험 마법 목록과 비용을 사용했다. 9.05초에 일반 시전과 첫 덩굴이 나왔고, 16.00초에 시험 피해로 분노를 발동했다. 연속 시전은 16.00, 16.40, 16.85, 17.30초에 나왔다. Unity에서 7.50초 이후를 1배속으로 재생해 일반·연속 시전의 자세와 방향, 첫 연속 시전과 함께 남는 분노 효과, 생성된 덩굴을 확인했다. 비공개 미리보기 28판은 이 기록의 0.40, 0.45, 0.45초 간격을 사용한다. 기록과 검수 로그는 `.generated/combat-full-audit/`에 보관한다.

차원문, 바람 조각, 소환 자세와 생성 효과의 제작 프롬프트는 [전투 효과 프롬프트](combat-cue-art/)에 보관한다. 소환 자세는 대기 스프라이트와 아래 중앙 피벗 및 PPU를 맞췄다. 바람 조각은 192×192에 중앙 피벗을 써서 서버가 보낸 폭발점을 기준으로 퍼진다.
