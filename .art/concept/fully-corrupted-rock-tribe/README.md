# 완전 타락 미니록과 큰 돌골렘

[두 유닛 비교 시안](../../../docs/pr-media/452/fully-corrupted-rock-tribe.png)

핀의 3단계 타락에서 검은 돌판, 붉은 타원 눈과 균열을 가져왔다. 미니록은 큰 머리와 짧은 팔다리를 살렸고, 큰 돌골렘은 높은 한쪽 어깨와 넓은 주먹으로 구분했다. 두 유닛에 황토색 돌 단면과 탁한 이끼를 남겼다.

큰 돌골렘의 떠 있는 파편 두 개는 어깨 꼭대기보다 낮게 배치했다. 전투용 스프라이트는 작은 화면에서 몸과 파편이 구분되는지 따로 확인한다.

내장 이미지 생성 도구로 [초안](prompt-v1.txt)을 만들고 [파편 배치](prompt-v2.txt)를 수정했다. 비교 시안은 전투용 스프라이트 제작에 쓰는 외형 참고 자료다.
