# 전기 계열 정지 시안 7종

[기존 유닛과 선택안 색 비교](selected-palette-review.png)

기존 바람·덩굴 정령과 물 계열 유닛을 같은 배경에 놓고 비교했다. 밝은 면과 어두운 면의 구분은 비슷하다. 선택안의 회보랏빛 그림자는 기존 전기 계열의 진한 노랑과 청색보다 차분하다. 특히 전기 창병·천둥 새·찌릿쥐는 번개와 얼굴의 노란색이 옅어져 전기 색이 덜 강하게 읽힌다. 폭풍편은 현재 작업본을 선택했다. 이 표는 외형 선택과 정지 시안 검토 기록이다.
