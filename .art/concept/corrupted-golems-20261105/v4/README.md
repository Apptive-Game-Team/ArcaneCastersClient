# 몸체 약 70%로 넓힌 돌 골렘 잠식

사용자가 한쪽 팔만 잠식된 v3에서 골렘의 약 70%까지 범위를 넓히도록 요청했다.
v4는 머리 일부, 몸통·복부, 한쪽 팔과 다리 및 반대쪽 다리 일부까지 검붉은 돌과
붉은 균열을 적용한다. 반대쪽 팔·어깨와 얼굴·무릎·발 일부에는 황갈색 돌과
초록 이끼를 남긴다. 70%는 시각적 목표이며 엄밀한 픽셀 면적 측정값은 아니다.

네 유닛, 다섯 런타임 PNG를 교체했다. `RockGolem` 기본·공격은 같은 부위가
잠식되며 `RockMage`의 나무 지팡이와 푸른 수정은 유지했다. 전신을 동일하게
어둡게 한 v2와 달리 원래 재질이 남은 불규칙한 경계를 유지한다.

- 도구: built-in `image_gen` 편집. 정확한 지시는 `prompts/`에 있다.
- 입력: v3 런타임 PNG. 기본 골렘 생성물을 다른 유닛의 잠식 범위·재질 참고로 사용했다.
- `sources/`: 채택한 생성물을 최대 512px로 정리한 입력.
- `finalize.py`: 커밋 `5cb14833`의 기존 캔버스·alpha bbox·바닥 여백에 맞춰 정규화.
- `validation.json`: 다섯 이미지의 크기·bbox·바닥 여백·metadata 보존 검증 수치.
- 최종 파일: `Assets/Resources/Game/sprites/`의 기존 다섯 PNG.
- 비교: `docs/pr-media/423/golems-corruption-70-v4.png`와
  `golems-corruption-70-v4-64px.png`. 위는 v3, 아래는 v4이며 실제 런타임 캡처는 아니다.

기존 `.meta` GUID·PPU·피벗과 prefab 연결은 변경하지 않았다.
원본 크기와 64px 비교를 확인했다. Unity 실제 플레이·빌드·배포는 수행하지 않았다.
