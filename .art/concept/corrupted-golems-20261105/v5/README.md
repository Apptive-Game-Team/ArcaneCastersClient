# 사용자가 선택한 검은 갑각 잠식

사용자는 v4의 보라색 표면이 멍처럼 보인다고 지적했다. 큰 골렘의 검은 갑각
시안을 확인한 뒤 “이 갑각 느낌으로 전체 적용”을 선택했다. 현재 v5는 색만
바꾼 표면 대신, 원래 돌 위에 검은 바위 판이 두께를 갖고 겹쳐 자라며 깊은 틈에서
붉은 빛이 새는 외형을 네 유닛·다섯 프레임에 적용한다.

- 갑각: 중성 숯색·흑연색의 넓은 면, 불규칙한 부러진 가장자리, 깊은 판 사이 틈.
- 잠식 범위: 앞서 요청한 약 70%를 시각적 목표로 삼고, 황갈색 돌과 초록 이끼가
  남은 부분을 비대칭으로 배치했다. 엄밀한 픽셀 면적 측정값은 아니다.
- 금지: 보라색·자주색 몸체 변색, 평평한 표면 위 붉은 선, 금속제 갑옷, 뿔·큰 가시·화염·오라.
- 고정: master-v2의 matte cut-paper 렌더링·3단계 명암·좌상단 빛·작은 타원 눈.
  유닛별 원래 체형·포즈를 유지하고 갑각의 작은 단차만 허용했다.
- `RockGolem` 기본·공격에서 갑각을 두른 몸 부위와 남은 원래 재질을 맞췄다.
  `RockMage`의 나무 지팡이와 푸른 수정은 유지했다.

## 제작 및 검증

built-in `image_gen`으로 기존 황갈색 원본에서 다시 편집했다. 큰 골렘은 원본과
master-v2 및 핀의 갑각 참고 시트를 입력했고, 나머지는 각각의 원본과 사용자가
선택한 큰 골렘의 재질을 참고했다. 정확한 지시는 `prompts/`에 있다.

`sources/`에는 채택한 입력을 최대 512px로 정리해 보존했다. `finalize.py`는
커밋 `e9b95b06`의 캔버스·alpha bbox·바닥 여백에 맞춰 최종 PNG를 만든다.
`validation.json`은 다섯 이미지의 수치와 `.meta` 동일 확인 결과다.
전체 생성물과 전체 스프라이트 검토 시트는 로컬 `generated/`, `review/`에 둔다.

최종 파일은 `Assets/Resources/Game/sprites/`의 기존 다섯 PNG다. 비교는
`docs/pr-media/423/golems-black-shell-v5.png`와 `golems-black-shell-v5-64px.png`다.
위는 v4, 아래는 v5이며 실제 런타임 캡처가 아닌 PNG 비교다.

기존 크기·bbox·바닥 여백·`.meta` GUID/PPU/피벗과 prefab 연결을 보존했다.
입력 종횡비 조정은 4.3% 이내다. 원본 크기와 64px를 확인했고 Unity 실제
플레이·빌드·병합·배포는 수행하지 않았다.
