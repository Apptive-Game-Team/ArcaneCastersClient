# 2026-11-03 — 컴퓨터 대전 난이도 선택과 최근 전적 표시

- Date: 2026-11-03
- GitHub Issue: #413
- Status: Implemented

## Goal

로비에서 난이도별 최근 다섯 경기와 추천을 보고 선택한 난이도의 봇과 대전한다.

## Non-goals

기존 빠른 연습의 상대 선정과 로컬 서버 동작은 별도로 유지한다.

## Context / Constraints

일반 봇 45개의 단계는 10월 27일 운영 MMR 분류를 사용한다. 로비 서버가 단계 목록과 전적을 제공하며, 새 클라이언트는 목록을 열 때만 요청한다.

## Approach (Checklist)

- 기존 로비의 연습 진입점과 대전 준비·실패·재접속 흐름을 확인한다.
- 추천 영역, 난이도 행, 시작 버튼을 로비 스타일로 구성한다. 목록만 세로 스크롤한다.
- 단계 지정 대전은 별도 POST로 요청한다. 구버전 서버에서 다른 상대와 매칭되는 일을 막는다.
- 로비 서버를 먼저 반영하고 클라이언트를 배포한다.

## Validation

Unity 2022.3.34f1 Play Mode에서 1280×720의 다섯 행은 스크롤바가 숨고, 1024×480의 열 행은 마지막 행까지 스크롤되는 것을 확인했다. 스크롤 전후 추천과 시작 버튼의 위치가 같았다. 예시 응답으로 행 선택, 빈 목록, 조회 실패와 복구를 검증했다. 배포 환경에서 실제 게임 세션을 만드는 검사는 남아 있다.

## Risks & Rollback

난이도 조회가 실패하면 이 화면에서 재시도할 수 있어야 한다. 클라이언트 변경을 되돌려도 기존 연습 API를 사용할 수 있다.
