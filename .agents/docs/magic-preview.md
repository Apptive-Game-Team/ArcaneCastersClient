# Recorded magic preview checks

When changing hit flashes, route both HP decreases and `Status.Damaged` through
the same cadence gate. An HP-only test passed while status updates still flashed
SandStorm rapidly. Burn/SandStorm use a one-second minimum interval; HP always
updates per server tick. Ordinary hits must not inherit this DOT cooldown.

When extending registrations, verify each JSON/meta GUID is exactly 32 hex
characters, uniquely referenced by the shared preview prefab, and that every
created object, projectile and effect name has a corresponding style. Static
coverage cannot prove viewport framing: run MagicPreviewTests and inspect both
the book explanation and deck hover in Unity before calling the batch verified.

Never infer target masks or secondary effects from art/names. ThunderBird is
airborne but attacks ground only; current WaterExplosion provides Burn and an
upward impulse, and FireDrop is plain damage. Read actual server initializers.
See `docs/fire-shot-preview.md` for current coverage and pending families.

Position projection endpoints use flat `x/y/z` in the actual server DTO, unlike
the nested object `position` field. Read both flat coordinates and the legacy
nested recording shape. A valid sprite/style lookup and a passing scenario cycle
test did not catch SeaSerpentHydroPump collapsing to a zero-length invisible beam;
assert its span and inspect a mid-projection frame. Reference endpoints track
live preview objects. Beams persist for the recorded duration/width; EvilEnt arms
extend, hold and retract rather than flying like ordinary projectiles.

Validate referenced sprite GUIDs against actual `.meta` files, then load the
prefab in Unity and assert non-null sprite references. MeteorShower's production
prefab still points to a deleted image GUID; the preview deliberately uses the
existing MeteorShower image without changing gameplay assets. A YAML reference
alone is not evidence that a sprite exists.

The catalog contains 85 magic recordings / 164 ordered situations. The remaining
64 are generated by `RemainingMagicPreviewTest`; run
`.agents/tools/expand-magic-previews.ps1 -CopyRecordings` after server export.
The script prints a patch for missing registrations/metas/styles; review and apply
it, never replace the entire prefab. It preserves existing mappings and UI layout.
Legacy Fire/Rock/Electric/WindSummon nests have no client prefab/art of their own
and use SeedNest as a visible proxy. Inspired uses the RallyingTotem marker;
empty StormStag charge-tier placeholders use increasing Overcharge marker sizes.
These proxies do not imply exact production artwork.

HP is green/orange by ownership. Yellow gauges show recorded TTL (including
freeze/recovery); ManaWell's cyan filling bar uses the recorded real charger rate.
Neither support mechanic should be represented as invented HP healing.
`CaptureComplexPreviewViewports` saves actual Unity preview-camera images under
`Temp/PreviewCaptures` at book/hover dimensions; these are isolated renderer
captures, not proof of full authenticated scene flow or UI placement.
